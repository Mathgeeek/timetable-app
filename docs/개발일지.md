# 기초시간표 빌더 — 개발일지

> 컴시간 알리미를 대체할 학교 시간표 자동 편성 웹앱
> Next.js 16 + TypeScript + Tailwind CSS 4

---

## 프로젝트 개요

- **목적**: 학기 초 기초시간표를 자동 편성하고, 교사가 수동으로 미세 조정하는 관리자용 도구
- **대상**: 수업계(교육과정) 담당 교사
- **저장소**: https://github.com/Mathgeeek/timetable-app (브랜치: `feature/core-timetable`)
- **실행**: `npm run dev` → http://localhost:3000

---

## 전체 작업 흐름 (사용자 시나리오)

```
1. 교사별 시수표 엑셀 업로드          → 수업 유닛 자동 생성
2. (선택) 학년별·요일별 교시 운영 설정  → 미운영 교시 제외
3. (선택) 동시수업(선택과목) 그룹 설정  → 편성안 파일 자동 불러오기 가능 ★
4. (선택) 교과 특별실 배정            → 기본 특별실 자동 등록 가능 ★
5. 기초시간표 작성 → ✨ 자동 배정 실행
6. 실패 교사 패널 확인 → 🔄 수동 교환/드래그로 조정
```

## 핵심 구현 내역

### 1. 자동 배정 엔진 (`lib/schedulingEngine.ts`)

제약 조건 기반 그리디 + **재배치(repair)** 알고리즘(CSP).

- **3단계 배정**:
  - Phase 1: 선택과목 그룹 동시 배정
  - Phase 2: 일반 수업 라운드로빈 + MCF(가장 제약 많은 수업 먼저) + 2패스(엄격→완화)
  - **Phase 3: 재배치 패스 ★** — 그리디로 막힌 수업을 위해, 그 칸을 막는 비고정 수업을
    빈 칸으로 밀어내(depth-1 backtracking) 자리를 만든다. (고정·선택과목 수업은 이동 금지)
- **하드 제약**: 교사 충돌, 학급 충돌, 특별실 수용량, 배정금지 슬롯, 미운영 교시,
  **교사 4연강 절대 금지**
- **엄격 제약**: 교사 **3연강 금지** (불가피하면 하드 폴백으로 허용)
- **연강 정책 (중요)**: 연강은 *교사* 기준만 적용. 학급은 하루 종일 연속 수업이 정상이므로 제약 안 함.
  (기존엔 학급 연강을 잘못 막아 불필요한 실패를 유발했음 → 제거)
- **3연강 보고**: 부득이 발생한 3연강 교사를 `threeConsecutive`로 반환 → 알림에 요일·교시까지 표시
- **소프트 제약(점수)**: 1·4교시 쏠림 방지, 같은 과목 같은 날 회피, 요일 부하 분산
- **특별실 재배치**: 재배치 패스가 교사·학급 충돌뿐 아니라 **특별실 꽉 참**도 해소
  (예: 미술실 1개 → 점유 중인 미술 수업을 빈 칸으로 이동시켜 자리 확보)
- **빠른 조회**: Set/Map 인덱스로 O(1) 충돌 검사 (재배치는 정확성 위해 배열 스캔)
- **미배정 진단**: 남은 수업은 사유를 자동 분류
  - `시수 초과`(학급/교사) = 수학적 불가 → 시수표·교시설정 조정 안내
  - 그 외 = 충돌 → 수동 조정 권장
- **결과 계약 변경**: `allAssignments`(재배치 반영 전체 시간표) 반환 → DashboardPage가 통째 교체

> 검증: `scripts/test-engine.ts` (npx tsx) — 6종 시나리오 통과.
> 정상 / 빡빡(35칸 꽉참, 재배치) / 시수초과 진단 / 미술실1개 재배치 / 연강 분산 /
> 3연강 강제발생(보고 확인 + 4연강 0건).

## ★ 편성안 파일 파서 (`lib/parseElectiveFile.ts`) — 가장 중요한 학습 내용

### 파일 형식

한컴 한셀(`.cell`)은 **ZIP 기반 OOXML**. 압축 해제 후 `xl/sharedStrings.xml` + `xl/worksheets/sheet1.xml`을 파싱.

### 해결한 버그 3가지 (순서대로)

| # | 증상 | 원인 | 해결 |
|---|---|---|---|
| 1 | "N선택 행을 찾지 못함" | sharedStrings/sheet가 `<x:si>`, `<x:t>`, `<x:c>` 등 **`x:` 네임스페이스** 사용 → 표준 태그명만 찾던 정규식이 0개 매칭 | 정규식을 `<x?:?si>`, `<x?:?t>`, `<x?:?c>` 로 통일 |
| 2 | C열 이후 반 데이터 누락 | **self-closing 빈 셀** `<x:c .../>` 이 다음 셀을 삼킴 | 셀 파싱 전 `replace(/<x?:?c\b[^>]*\/>/g, '')` 로 빈 셀 제거 |
| 3 | 그룹 의미가 틀림 | "N선택" 행 12개 반을 한 덩어리로 묶음 (잘못된 이해) | **이동학급(인원) 행 기반 코호트 그룹핑**으로 재설계 |

### ★ 핵심 개념: 코호트(동시 배정 묶음)

**"이동학급(인원)" 행이 동시 배정의 기준이다.**

- 한 "N선택" 블록 구조: `[과목 행] → [수강인원 행] → [이동학급(인원) 행 + 연속 행]`
- 이동학급 행에는 각 반(컬럼) 학생이 **어느 출신 학급에서 모였는지**가 적혀 있음
- **출신 학급을 공유하는 컬럼끼리 = 같은 학생 풀이 나뉘어 들어간 수업 = 반드시 같은 시간**

예) 2선택
```
9반 컬럼(사회문제탐구)  ← 출신 {9반, 10반}
10반 컬럼(생활과윤리)   ← 출신 {9반, 10반}
→ 두 수업은 같은 시간에 배정 (= 하나의 코호트)
```

### 알고리즘

1. 행을 순회하며 "N선택" 블록 탐지
2. 블록 내 이동학급 행 + 연속 행에서 컬럼별 "출신 학급" 집합 수집
3. **Union-Find**로 출신 학급 공유하는 컬럼끼리 묶음
4. 2개 이상 묶인 코호트만 동시배정 그룹으로 생성 (단독 수업 제외)

### 검증 결과 (26학년도 3학년 이동수업 편성안 → 16개 코호트)

- 2선택 ① 11·12반 / ② **9·10반(사문탐+생윤)** ← 사용자 확인 예시
- 5선택 ① 4·5·7·8·12반 (5개 동시)
- 6·7선택 각 7개 동시, 8선택 6개 동시
- 9선택 ①~④, 10선택(음악/미술) ①~④

## 미배정(실패)이 발생하는 실제 원인

물리적으로 운영 중인 시간표인데도 자동배정이 실패하는 이유 (배정금지 때문 아님):

1. **특별실 수용량 미설정** — 운동장/음악실/컴퓨터실에서 여러 반 동시 수업인데 수용량 1로 인식 → 충돌
2. **선택과목 코호트 미설정** — 동시 진행 선택과목이 서로 시간 충돌로 처리
3. (배정금지는 설정 안 했으면 0개 → 영향 없음)

→ **해결 순서**: ① 기본 특별실 자동 등록 → ② 편성안 파일로 코호트 자동 등록 → ③ 자동 배정

## 주요 타입 (`app/types/index.ts`)

- `TeacherUnit`: 시수표에서 추출한 수업 유닛 (교사·과목·학년·반·시수)
- `Assignment`: 시간표에 배치된 수업 (+ `isFixed`)
- `ElectiveGroup`: 동시수업 그룹 (`unitIds[]`)
- `SpecialRoom`: 특별실 (`capacity`, `unitIds[]`)
- `BlockedSlot`: 교사별 배정금지 슬롯
- `PeriodConfig`: 학년별·요일별 최대 교시 수
